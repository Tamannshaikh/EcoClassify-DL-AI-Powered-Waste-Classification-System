# Features

## Core Features

### 1. Waste Image Classification
Upload an image and classify it into:
- Cardboard
- Glass
- Metal
- Paper
- Plastic
- Organic

### 2. Confidence Score
Show confidence for the predicted class.

### 3. Probability Distribution
Show probabilities for all classes using a horizontal bar chart.

### 4. Drag and Drop
Allow image drag-and-drop.

### 5. Image Preview
Show the selected image before prediction.

### 6. Prediction History
Show recent predictions.

### 7. Model Performance
Show:
- Test accuracy
- Precision
- Recall
- F1
- Confusion matrix

### 8. Training Curves
Show:
- Training accuracy
- Validation accuracy
- Training loss
- Validation loss

### 9. Grad-CAM
Optional explainability feature showing where the model focused.

### 10. Dataset Explorer
Display:
- Number of images
- Number of classes
- Class distribution
- Train/validation/test counts

### 11. Model Information
Display:
- Model name
- Version
- Input size
- Number of classes
- Parameters
- Framework

## Optional Advanced Features
- Compare CNN vs MobileNetV2
- Batch image prediction
- Export prediction result
- Camera capture
- Model retraining page
- Download Grad-CAM image
